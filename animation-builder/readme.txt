== Description ==
<h3>Animation Builder - Complex scroll-triggered animation with no coding required.</h3>
Animation Builder lets you craft everything from subtle transitions to complex, multi-stage scroll-triggered animations — all within a modern, familiar interface.

With intuitive controls and powerful features, you can build animations that respond to triggers, follow logical rules, and combine seamlessly to create a rich, interactive experience on your website — all with a fraction of the effort typically required.

<h3>Features</h3>
<strong>Scroll triggered</strong> - All animations respond to your scrolling, activating only when visible in the browser to ensure nothing is missed and performance remains smooth.
<strong>Lightweight & performant</strong> — Minimal footprint, optimized for fast, smooth animations.
<strong>Powered by GSAP Animation Framework</strong> — Built on the industry-standard animation engine for reliable, high-performance animations.
<strong>Zero-config defaults</strong> — works straight out of the box.
<strong>Beginner-friendly</strong> — no coding knowledge required.

<h3>The 4 types of animation included within Animation Builder</h3>
Animation Builder is designed to make animations effortless for everyone — whether you’re a seasoned developer or someone who has never touched JavaScript. With multiple ways to create and trigger animations, you have complete freedom to choose the approach that works best for you.

<strong>1. Simple Animation Builder</strong>
A clean, visual interface for creating smooth, single-step transitions. Ideal for quick enhancements when you need movement without complexity.

<strong>2. Advanced Timeline Builder</strong>
The heart of Animation Builder — a full-fledged timeline editor that lets you design professional, multi-stage animations with precision and control. No coding required, just creativity and a bit of animation logic.

<strong>3. Ready-to-Use CSS Classes</strong>
Instantly add motion to any element with our library of predefined CSS animations. Perfect for quick effects that grab attention — no setup required.

<strong>4. Legacy Activations</strong>
A tried-and-true method for scroll-based effects. Elements activate as they enter the viewport, enabling elegant CSS transitions between states — great for subtle, performance-friendly animations.

<h3>Benefits</h3>
<strong>Attract Users to Key Areas</strong> - Apply animations strategically to highlight the sections that matter most.
<strong>Improves engagement</strong> - studies show that web animations can improve "time on page" by up to 15%.
<strong>Increase Credibility</strong> - Polished, purposeful animations can make your website appear more credible.

== Installation ==
<h4>Ensure PHP 7.0 or higher is installed before proceeding</h4>

<ol>
  <li>Go to the <strong>Plugins</strong> menu in your dashboard.</li>
  <li>Search for <strong>“Animation Builder”</strong> in the plugin repository.</li>
  <li>Click <strong>“Install Now”</strong>, then <strong>“Activate”</strong> to enable the plugin.</li>
</ol>
